## 1. `R-P1-01`：重建 latest-null 语义

### 1.1 裁决

撤销 plan-r1 的 `LATEST_VERSION_RULE_UNCHANGED` 与 state
`yanked-latest-null-denied`。替换为具名 invariant：

`YANK_REVOCATION_NOTICE_REACHABILITY`

> 对一条真实 `SkillVersionYankedEvent`，若本次 yank 同一事务把
> `skill.latestVersionId` 清为 `null`，不得仅因该自致状态而吞掉撤回通知。通知资格仍使用
> 处理时的账号、namespace、membership、visibility、hidden 与平台角色事实；actor 仍跳过。

理由：撤回通知的收件人正是可能已安装被撤版本的人；以本次撤回造成的 latest-null 再否定
本次撤回消息，是过滤器自我否定。base 对订阅者无条件 dispatch，r1 candidate 把普通 PUBLIC
订阅者由有通知改成零 sink，因此无论最终维护者是否接受，这都是必须在 PR 正文披露的存量行为
变化。Planner 不以一条符合旧计划的绿测试证明旧计划正确，现据反例重建。

### 1.2 checker interface 与优先级

在 `VisibilityChecker` 定义显式 access purpose（名称可按仓库风格调整，但只能表达以下两种
语义）：

- `METADATA_READ`：旧两个 overload、subscribe、published fan-out 的默认目的；原
  `latestVersionId == null` owner-only 规则不变。
- `YANK_REVOCATION_NOTICE`：仅 yanked subscriber listener 使用。它只豁免
  `latestVersionId == null` 这一 publication-state guard，再按当前 `hidden` 与
  PUBLIC / NAMESPACE_ONLY / PRIVATE 规则判定；账号 missing/disabled、namespace archived、
  current membership、平台角色通道政策以及 actor skip 均不被豁免。

full-context overload 必须接收 purpose；旧 overload 委托 `METADATA_READ`。published listener
传 `METADATA_READ`，yanked listener 传 `YANK_REVOCATION_NOTICE`。不得把 purpose 藏在 boolean
参数里，不新增 `wasPublished`、历史 snapshot、event record 字段或 producer 改动。

purpose 的例外必须落在 `VisibilityChecker` 内。`SubscriberAccessResolver` 仅接收并原样转发
purpose；不得出现 `event instanceof`、`latestVersionId == null`、visibility、account status、
namespace status 或 role allow/deny 分支。listener 选择与其具名 event method 对应的 purpose
属于编排，不属于第二套授权判定。

### 1.3 可证伪状态与 probe

- `yank-last-public-public-subscriber-receives-revocation`：ACTIVE account、PUBLIC、not hidden、
  非 owner、无 namespace/platform role、last PUBLISHED 被 yank 后 latest-null；非 actor 获得
  exactly one `SUBSCRIPTION_VERSION_YANKED` row 与同 recipient SSE。
- `yank-last-public-private-ordinary-denied`：同为 latest-null，但 PRIVATE ordinary member 仍
  0 row / 0 SSE；namespace admin control 收到一次。
- `yank-last-public-hidden-ordinary-denied`：hidden ordinary subscriber 仍 0/0；owner/admin
  control 收到一次。
- `yank-last-public-removed-or-disabled-denied`：removed member 与 disabled account 均 0/0。
- `publish-latest-null-still-owner-only`：同一 skill state 走 published/metadata purpose 时仍拒绝
  非 owner，证明例外没有扩散到 ordinary read。
